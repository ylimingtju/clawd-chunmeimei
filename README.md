# 单依纯《纯妹妹》二专 × Clawd 视频项目

为单依纯二专《纯妹妹》制作的 Clawd 动画视频：先出分镜与关键帧，再用代码逐帧绘制动画并合成。

## 目录

| 目录 / 文件 | 内容 |
|---|---|
| `分镜/` | 分镜脚本 v1–v4、BPM 清单 |
| `关键帧/` | 各批次关键帧与 v4 样张 |
| `造型图/` | 定调提示词、代码绘制的 Clawd 造型与逐曲动画脚本 |
| `codex 版本/` | Codex 版本的制作计划、报告、时间轴与渲染代码 |
| `Opus5.5 版本/` | Opus 5.5 版本（视频文件未入库） |
| `字体/字体清单.md` | 使用的字体及来源（字体文件未入库） |
| `制作交接.md`、`素材来源与说明.md`、`素材覆盖表.md` | 制作交接与素材记录 |

## 未包含的内容

- **视频**：全部 mp4 / MOV（成片、样片、分段）体积过大，未入库。
- **字体文件**：请按 `字体/字体清单.md` 自行下载。
- **`素材/`**：专辑封面、MV 截图、现场造型图等第三方版权素材，不在公开仓库中分发，来源见 `素材来源与说明.md`。
- **中间产物**：抽帧、检查输出、绘制层缓存。
