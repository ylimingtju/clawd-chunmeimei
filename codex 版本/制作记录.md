# 制作记录

2026-10-16：开始制作。已完整读取指定分镜、BPM、所有源脚本，并查看 24 张定稿 PNG。原文件已记录 SHA-256。

## 已识别的约束差异

- D 与 S10 的源脚本含 70 像素上下遮幅；正片按 1920×1080 无黑边要求移除新副本中的遮幅。
- C 源脚本另画 1.6×1.6 格握麦小钳子；正片保留原 1×2 手臂并整块转动握麦。
- 03-M 原设计写背后跟拍绕回正面，但 v3 第一节未把此处列为三维镜头；采用平面沿月光路跟拍与镜头平移，不用横向压扁模拟转身。
- 00 的黑场亮珠与 10-c 最后两拍淡黑是 v3 指定的片头/片尾；场景之间不使用淡化、闪白或整屏划变。

## 实际实现与 v3 的差异

以下是实现近似，不能视为逐字复现了 v3 的全部空间运动。各处仍保留角色动作、两套世界、交界遮罩以及遮罩内外同步换装。

| 段 | v3 原设计 | 实际实现 | 原因与限度 |
|---|---|---|---|
| 01-E | 链上一颗珍珠变成泡泡，包住主角落入书中 | 泡泡从主角右侧靠近并扩大，主角跳起后落入纸艺世界，膜边跨过角色换装 | 未制作珍珠链上单颗珠子的脱离运动；保留泡泡膜穿越 |
| 01-M | 主角站在翻起的书页上，镜头随翻页转动 | 曲线纸边通过角色，背景跟随平移和轻推，角色维持统一脚底锚点 | 纸页用平面曲边表达，没有制作完整书页曲面翻卷 |
| 02-M | 花瓣连续展开成为毛毡幕布 | 花到脸前后，幕布缝扩大，主角起身穿过 | 花与幕布之间采用形状接续，没有逐片花瓣变形 |
| 03-E | 灯泡成为同一颗月亮 | 沿灯线滑过发光灯泡处的交界，进入有月亮的油画夜空 | 灯泡与远处月亮是两个绘制层，没有做同一物体的位置形变 |
| 03-M | 背后跟拍并绕到正面 | 月光路前沿通过角色，采用平面跟拍和镜头平移 | v3 的三维清单未列此处；不增加角色转身，也不压扁身体 |
| 05-M | 花心内的舞台随镜头放大 | 保留原样片的花心遮罩、背景镜头、独立角色及脚底锚点；花心内舞台始终以覆盖视口的尺度绘制 | 测试中发现缩小背景时出现平色区域，改用有裁切余量的舞台层 |
| 07-M | 完整画面缩小成手机屏幕，主角从屏幕走出 | 手机框收拢并下移，框内保留夜城世界；主角跨过左侧边框换白裙 | 手机内以视口裁切表达，没有将角色与整个旧画面一起缩成缩略图；角色脚底和格大小保持连续 |
| 09-E、09-M | 镜头抬为俯视沙画台，再回平视 | 用沙画材质、流沙前沿及背景轻推表达空间变化 | 没有额外制作可转动的三维沙台；角色没有新增三维视角 |
| 10-E | 越过台口后转成侧面跟拍 | 沿斜台口越界后横向跟随飞行，角色保持平面完整轮廓 | 三维镜头限定清单未列 10；没有把平面身体压成侧面 |
| 10-a | 钩针流苏拖出光尾 | 服装裁在 12 格内，另画不属于服装的光丝轨迹 | 原 D 脚本中的长拖布会超过下摆限制；保留光尾意象 |

03-a 的书写使用手工录入的「向、日、葵、朝、着、夜」笔画中心线，按常用笔顺揭示马善政字体的原轮廓。字体没有逐笔轮廓数据，笔画交叉处按最近中心线分配，属于代码近似笔迹。

08-a 按“一拍安静”解释为第 1 拍保持宣纸、鼓、铃与素纱；第 2 拍起抛花和泼墨，第 5 拍再触发一轮重拍。歌名仍从 a 段首帧出现。08 全部印章字面仅为「茉」「莉」。

## 测试中发现并已修复

- 万花筒旋转露出三角形背景边角：改为按旋转角度计算足够的背景裁切余量。
- 周围珐琅角色下缘裁切：按身体中心计算旋转后的脚底位置。
- 01-b、02-b、03-b 出现重复麦克风：保留定稿角色层内的麦克风，取消重复绘制。
- 04-M 的金裙和羽饰在最后才出现：将定稿服装作为三维模型前表面纹理，并作深度测试。
- 05-M 缩小的舞台背景出现平色填充：调整背景缩放，确保花心内有完整绘制内容。
- 07 背面夹克过暗：接入已绘制的背面皮革材质，保留一排居中的四条腿。
- 08-a 标题与泼墨重叠：移到左上留白，并补出第一拍的安静背景。
- 09-a 擦字区域边界生硬：改为沿波浪前沿裁去标题像素，保留原沙画背景。
- 06 镜像数量：补齐为主角加五个后方镜像。
- 03-a 文字原先只是逐字显露：补录笔画路径；同时把标题移离月亮，避免最后一个字失去对比。

- 编码后接点复查发现三维相机横轴与平面格画布相反，导致进入三维时麦克风左右翻转：在正片副本中统一相机方位及输出横轴，保留真实箱体尺寸；复核接点邻帧后重渲染受影响的 7 个子段（含 07-M 复用三维正面的首帧）。

## 验证边界

每个子段先导出 7 张 1920×1080 测试帧，其中包含首帧、末帧和时长中点。静帧检查覆盖比例、材质、遮挡、交界与标题；它不能替代对每一帧艺术效果的逐帧人工审片。

角色尺寸由几何断言和统一格画布检查，拼接点另核对脚底位置、格大小、倾角、三维角度及造型标签。最终编码信息、实际帧数、原文件哈希和拼接点图像检查结果见《制作报告.md》及 `检查/成片核验.json`。
