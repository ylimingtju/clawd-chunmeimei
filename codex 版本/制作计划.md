## 穿越实现

所有背景不含主角；主角在统一格坐标画布单独绘制，脚底 (8,12) 为锚点。身体和服装不受背景镜头非等比变形。双世界同帧绘制，共享位置、大小、倾角、手臂和腿姿势，按具有物理含义的交界遮罩合成。

| 段名 | 交界 | 实现 |
|---|---|---|
| 01-E | 泡泡膜 | 主角从下方花瓣跳起，泡泡包住后下降；镜头进入泡泡，膜的移动曲线逐像素分隔珐琅与纸艺。 |
| 01-M | 翻页纸边 | 主角沿纸页走动；曲面纸边随脚步翻起，纸边两侧各绘一套世界和造型，镜头轻转。 |
| 02-E | 纸云切面 | 纸云下降到脚下，主角跳上后上升；切面从脚到头通过，纸云进入毛毡云海。 |
| 02-M | 花瓣幕布缝 | 花开到脸前，主角伸臂醒来，穿入展开的花瓣幕布；缝内为毡布舞台，镜头随它靠近。 |
| 03-E | 灯泡/月亮边缘 | 抓住灯线横向滑行；灯泡附近的世界接缝变为月亮，滑过接缝即变油画素身。 |
| 03-M | 月光路尽头 | 主角起身沿月光路走到舞台，路尽头的光边分隔花田和舞台；按三维使用范围限制采用平面跟拍。 |
| 04-E | 光斑边缘 | 主角向左走出光斑，clawd3d 真正转侧面；边缘两侧分别油画和灰蓝胶片。 |

## 制作与验证

按 00→10 顺序。每个 E/a/M/b/c 子段先导出 7 张测试帧（含首尾和穿越中点），检查后再编码。每个曲目结束边界的角色状态传递到下一曲 E；所有子段拼接点保留前后各 2 帧和对照图。

每个造型及动态姿势调用 check_proportions；对腿整块平移另外检查宽高仍为 1.3×2、和身体保持连接。三维厚度 8、腿一排居中。静态背景每进程缓存；不在 import 时启动多进程；耗时纹理限制到角色或遮罩外接框。

已有文件在首次制作前记录 SHA-256，完成时重查。最终输出 H.264 / yuv420p / 1920×1080 / 30 fps，无音频。实测渲染时间、调整和遗留问题写入制作记录与检查报告。
